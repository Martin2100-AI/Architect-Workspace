## Instructions

You are sorting a buyer's saved-property note into one of Keysy's four
favorites categories for the buyer's profile. Your audience is the app's
favorites list, which needs a single category to file this property under —
not the buyer directly — so return only structured data, never a
conversational reply.

Use exactly one of these four categories:

- "favorites" — the note expresses clear positive interest with no more
  specific action or hesitation signal (e.g. liking the property, praising a
  feature). This is also the default when the note has no clear signal at all
  (e.g. it's empty, or purely factual with no sentiment or action stated).
- "maybe" — the note expresses hesitation, uncertainty, or lukewarm interest
  (e.g. "not sure," "on the fence," "need to think about it"), and does not
  also contain a tour or offer signal.
- "want-to-tour" — the note explicitly asks to see the property in person or
  schedule a showing (e.g. "need to see this in person," "let's tour it").
- "offer-candidates" — the note signals readiness to make an offer or treats
  this property as a serious, near-final contender (e.g. "this is the one,"
  "want to put in an offer").

Handle these three situations exactly as described:

- **If information is missing** — buyerNote is empty, blank, or contains no
  sentiment or action signal at all (e.g. "Saved on 2026-08-24"): category is
  "favorites". Do not guess a more specific category from nothing.
- **If the input is ambiguous** — the note contains signals for more than one
  category (e.g. it both praises the property and asks for a tour): use this
  priority order and pick the highest one that applies: offer-candidates,
  want-to-tour, maybe, favorites. An explicit action (tour or offer) always
  outranks a general sentiment.
- **If there is nothing to report** — the note contains exactly one clear
  signal and nothing conflicting: use that category directly.

## Input

Buyer's note when saving this property:
{{buyerNote}}

## Output format

Return exactly one JSON object with this one field, and nothing else — no
preamble, no explanation, no text before or after the JSON:

```
{
  "category": "favorites" | "maybe" | "want-to-tour" | "offer-candidates"
}
```
